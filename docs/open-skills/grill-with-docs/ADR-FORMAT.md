# ADR Format

Use ADRs only for decisions that are hard to reverse, surprising without context, and based on real tradeoffs.

```markdown
# ADR-NNNN: [Decision Title]

## Status

Accepted | Proposed | Superseded

## Context

[What problem or tradeoff forced the decision?]

## Decision

[What did we choose?]

## Consequences

### Positive

- [Benefit]

### Negative

- [Cost/risk]

## Alternatives Considered

- [Alternative] — rejected because [reason]
```

Avoid ADRs for obvious, temporary, or purely mechanical choices.
