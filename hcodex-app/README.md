# codex-ide

Personal desktop IDE built on top of the open-source Codex engine
(`codex app-server`). Tauri 2 (Rust) + React/TypeScript.

```
codex-ide/
├── src-tauri/src/lib.rs   spawns `codex app-server`, bridges JSONL <-> webview events
├── src/lib/rpc.ts         JSON-RPC 2.0 client (requests, notifications, server->client requests)
├── src/protocol/          TS types generated by `codex app-server generate-ts`
└── src/App.tsx            agent panel: thread/turn, streaming items, approvals, model picker
```

## Prerequisites

- Sibling checkout of `openai/codex` built from source:
  `~/github/codex/codex-rs/target/debug/codex` (`cd codex-rs && cargo build --bin codex`)
- A `CODEX_HOME` with a provider config. Default: `~/.codex-dev/config.toml`
  (custom `model_providers.*` with `wire_api = "responses"`).
- Node 22 + pnpm, Rust stable.

## Run

```bash
export LOCAL_PROXY_API_KEY=...       # whatever env_key your provider config uses
pnpm install
pnpm tauri dev
```

Env overrides read by the Rust side:

| var            | default                                            |
|----------------|----------------------------------------------------|
| `CODEX_BIN`    | `~/github/codex/codex-rs/target/debug/codex`       |
| `CODEX_HOME`   | `~/.codex-dev` if it exists, else codex's default  |
| `CODEX_IDE_CWD`| current dir                                        |

## Regenerate protocol types

```bash
~/github/codex/codex-rs/target/debug/codex app-server generate-ts --out src/protocol
```
