# codex-ide

Personal desktop IDE built on top of the hcodex harness (`hcodex app-server`,
fork of openai/codex — see `~/github/codex` branch `my-harness` / HCODEX.md).
Tauri 2 (Rust) + React/TypeScript.

```
codex-ide/
├── src-tauri/src/lib.rs   spawns `hcodex app-server`, bridges JSONL <-> webview events
├── src/lib/rpc.ts         JSON-RPC 2.0 client (requests, notifications, server->client requests)
├── src/protocol/          TS types generated by `hcodex app-server generate-ts`
└── src/App.tsx            agent panel: thread/turn, streaming items, approvals, model picker
```

## Prerequisites

- `hcodex` installed (`~/.cargo/bin/hcodex`, see HCODEX.md in the codex repo).
- Responses API proxy running at `http://127.0.0.1:8181/v1` (hcodex's default
  `local-proxy` provider); no login or API key needed.
- Node 22 + pnpm, Rust stable.

## Run

```bash
pnpm install
pnpm tauri dev
```

Env overrides read by the Rust side:

| var            | default                                                              |
|----------------|----------------------------------------------------------------------|
| `CODEX_BIN`    | `~/.cargo/bin/hcodex`, else `.../codex-rs/target/release/hcodex`     |
| `CODEX_HOME`   | `~/.hcodex` if it exists, else the binary's default                  |
| `CODEX_IDE_CWD`| current dir                                                          |

## Regenerate protocol types

After every upstream sync / hcodex rebuild:

```bash
hcodex app-server generate-ts --out src/protocol
pnpm exec tsc --noEmit   # catch API drift
```
